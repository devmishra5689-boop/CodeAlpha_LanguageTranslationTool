
AI Language Translation Tool

Project Overview

This project is an AI-based Language Translation Tool developed using Python and Gradio.

It allows users to translate text between multiple languages using an online translation service.

Features

- Simple and user-friendly interface
- Multiple language support
- English to Hindi translation
- French, Spanish and German language support
- Real-time text translation
- Copy-friendly output

Technologies Used

- Python
- Gradio
- Requests Library
- Google Translation Web Endpoint

Installation

Install the required libraries:

pip install -r requirements.txt

Run the Project

python app.py

Project Files

- app.py – Main application code
- requirements.txt – Required Python libraries
- README.md – Project documentation
